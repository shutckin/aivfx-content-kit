# Бриф и спрос: «Почему картинки из нейросети выглядят пластиково»

Этап 1 скилла `aivfx-blog`: тема из спроса и вопросов.

> Цифры спроса в этом файле условные, для примера формата. Настоящие цифры берутся только из Вордстата владельца, с датой и регионом.

## Пять вопросов брифа

Агент задал их одним сообщением, владелец ответил так:

| Вопрос | Ответ владельца |
|---|---|
| Запрос и интент | «почему нейросеть рисует пластиковые лица». Человек уже генерирует картинки, результат его не устраивает, ему нужна причина и способ поправить промпт |
| Для кого | дизайнеры, SMM, авторы блогов и небольшие студии, которые делают обложки и рекламные кадры в генераторах картинок |
| Цель | охват по кластеру «нейросеть пластиковая кожа», переход в статью про лук, клик по партнёрской ссылке на условный курс по генерации |
| Ограничения | никаких обещаний «картинка как с камеры», только приёмы и честные пределы; названия моделей без номеров версий, если версию не сверили сегодня; одна партнёрская ссылка с раскрытием |
| Кто согласует и когда | владелец сайта, в течение дня после синопсиса |

## Спрос

### Подсказки поисковика

Команда:

```bash
python3 skills/aivfx-blog/scripts/suggest.py "нейросеть пластиковая" --out spros-plastik.csv
python3 skills/aivfx-blog/scripts/suggest.py "промпт реалистичное фото" --out spros-realizm.csv
```

Подсказки дают формулировки, но не частотность. Что попало в работу (список условный, для примера формата):

- почему нейросеть рисует пластиковые лица
- нейросеть пластиковая кожа как убрать
- промпт для реалистичного фото
- как сделать фото нейросети не таким идеальным
- эффект плёнки в промпте

### Вебмастер и Search Console

- Вебмастер: запросы про «реалистичное фото в нейросети» показываются на позициях 11-15, кликов почти нет (условно). Показы собирает старое сравнение генераторов картинок, где реализму отведён один абзац.
- Search Console: тот же кластер по-английски («ai images look plastic») даёт показы из разных стран (условно). Английская версия возможна второй волной.

## Тип и решение

- Тип: информационный с практическим хвостом. Человек хочет понять причину и сразу получить, что вставить в промпт.
- Новая статья или обновление: новая. Сравнение генераторов картинок обновим ссылкой на неё, абзац про реализм там сократим.
- Площадка и язык: блог сайта, ru. Английская версия второй волной.
