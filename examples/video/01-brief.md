# Этап 0. Приём брифа: ролик для кофейни «Тихий помол»

> Бренд, люди, адрес и цифры вымышленные, условно. Опросник: `skills/aivfx-concept/templates/brief-questions.md`.

Что пришло от клиента (лежит как есть в `inbox/`): три голосовых, фото
стаканов и вывески, скрин чужого ролика, который «нравится по
настроению». Ниже то же самое по опроснику.

## Сказано прямо

- «Нужен ролик в Reels и Shorts, секунд тридцать, чтобы к нам заходили
  утром, а не только днём».
- «Мы мелем зерно под каждую чашку, это наша фишка, это надо показать».
- «Открываемся в семь, рядом трамвайная остановка».
- «Лица бариста можно, Игорь согласен сниматься» (условно).
- «Без цен в ролике, они меняются».

## Подразумевается, но не сказано (мои выводы)

- Зритель живёт или работает рядом: ролик продаёт привычку зайти по пути,
  а не кофе вообще. Вывод, проверить у клиента.
- Утро до семи снять тяжело: на рассвете на улице темно и мокро, свет
  каждый день разный. Виды улицы на рассвете разумнее генерировать, а
  внутри кофейни снимать.
- «По настроению как в референсе» значит медленный ритм и тёплый свет, а
  не монтаж того ролика (разбор ниже).

## 1. Задача

- [x] * Что ролик должен сделать: запомниться жителям района и привести
      утренних гостей (сейчас утро пустое, со слов клиента, условно).
- [x] * Кто зритель: соседи и те, кто едет мимо на трамвае, 22-45 лет,
      про кофейню могли слышать, но утром не заходили.
- [x] Одно действие после ролика: зайти завтра утром по пути.
- [x] Чем отличается от соседей, словами клиента: «мелем под каждую
      чашку», «у нас тихо, музыка не орёт».

## 2. Формат

- [x] * Площадка: Reels и Shorts.
- [x] * Соотношение сторон: 9:16, одна версия.
- [x] * Хронометраж: 30 секунд точно.
- [x] Звук: смотрят без звука, ключевые слова дублируются титрами.
- [x] Язык: русский, других версий нет.

## 3. Сроки и люди

- [x] * Дата сдачи мастера: 24.10.2026 (условно).
- [x] * Кто финально согласует: владелец кофейни Марина (условно);
      переписка идёт с ней же, отдельного маркетолога нет.
- [x] Кругов правок заложено: два.
- [x] Когда клиент отвечает: будни после 15:00, утром она на смене.

## 4. Материалы от клиента

- [x] * Фото продукта: бумажный стакан фронтально, в три четверти и рядом
      с ложкой для масштаба; керамическая чашка только фронтально.
      Не хватает чашки в три четверти: попросить.
- [x] Логотип в векторе: SVG есть.
- [x] Цвета и шрифты бренда: гайдлайна нет, цвета сняты с вывески и
      стакана (тёмный эспрессо, кремовый, терракотовый акцент).
- [ ] Сценарий или закадр: нет, пишем сами.
- [x] Видео-референсы: один, разбор ниже.
- [x] Свои исходники: нет, снимаем один день на месте.
- [x] Голос: без диктора, только титры и звуки кофейни.
- [x] Музыка: из свободной библиотеки, с понятной лицензией.

## 5. Ограничения

- [x] Нельзя: цены, сравнение с сетевыми кофейнями, «лучший кофе в
      городе».
- [x] Обязательно: адрес и часы работы в финале.
- [x] Реальные люди в кадре: бариста Игорь, согласие письменно (условно,
      копия в `inbox/consent-barista.pdf`). Гостей в лицо не снимаем.
- [x] Генерация: можно для улицы и фонов, кофейню, бариста и стакан
      только снимать или по реальному фото.

## 6. Мои выводы (не спрашивать, проверить)

- Подразумевается: ролик живёт в сетке месяцами, поэтому без дат и
  акций.
- Неоднозначно: «тихо» это про музыку или про людей? Беру как
  настроение: мало людей в кадре, звуки помола вместо музыки в начале.
- Главный риск: трамвай и улица на рассвете из генерации должны совпасть
  по свету со съёмкой внутри, иначе склейка видна.
