# Пример: сайт маленького бизнеса от брифа до очереди выката

Здесь один вымышленный сайт проведён через `aivfx-site` и `aivfx-secure`:
одностраничник мастерской по ремонту обуви и сумок «Каблук и шов» с
прайсом, фото работ и формой записи, которая присылает заявку в Telegram.

> Всё вымышленное, условно: мастерская, адрес, цены, даты и цифры замеров. Ключи в выводе проверки заведомо фальшивые и показаны с маской. Кода сайта в примере нет: показаны документы, которые агент ведёт вокруг кода.

## Порядок файлов

| Файл | Шаг | Скилл | Что внутри |
|---|---|---|---|
| `01-brief.md` | 2. Бриф и 8. Холодная проверка | `aivfx-site` | понял так, беру по умолчанию, три вопроса с готовыми ответами, что мог упустить, не буду делать, стиль; в конце итог холодной проверки |
| `02-browser-check.md` | 5-6. Браузер и дизайн-аудит | `aivfx-site` | телефон 375, компьютер 1440, скорость, консоль и сеть, две найденные и исправленные проблемы |
| `03-secure-report.md` | перед выкатом | `aivfx-secure` | реальный вывод `scan_secrets.py` по учебной папке с фальшивыми ключами, девять проверок в формате скилла, итог, ответ владельца |
| `04-deploy-queue.md` | 7. Очередь выката | `aivfx-site` | три пункта ждут выката, чек-лист перед выкатом, почему выката ещё не было |

## Как повторить проверку ключей

Скрипт по папке примера, из корня репозитория:

```
$ python3 skills/aivfx-secure/scripts/scan_secrets.py examples/site --no-git
Чисто: похожих на ключи строк не найдено.
```

Код выхода 0. `--no-git` здесь нужен потому, что папка примера лежит
внутри репозитория набора, и без флага скрипт пошёл бы по истории всего
набора, а не сайта.

Прогон с находками (код 1) сделан на учебной папке вне репозитория, вывод
и разбор в `03-secure-report.md`. Чтобы повторить у себя: заведи пустую
папку, положи туда `.env` с выдуманным ключом и файл с токеном в коде,
сделай коммит и запусти скрипт. Настоящие ключи для этого не нужны и
опасны.

## Что в примере сделано по правилам набора

- Бриф на один экран, три вопроса и у каждого готовый ответ. Блокирующий
  один, работа началась сразу.
- В «что ты мог упустить» находки из файлов владельца (две цены на
  набойки, старое фото вывески), а не общие слова.
- Фото только настоящие, генерации нет: «до и после» не подделывается.
- Шрифты Manrope и Inter, цены сансом с `tabular-nums`, без моноширинных.
- Сайт открыт на телефоне и компьютере, найденные мелочи исправлены до
  сдачи, условные цифры замеров помечены.
- Тестовые заявки шли в тестовую группу, не владельцу.
- Аудит безопасности сначала отчётом, правки только после «да» владельца,
  ключи сменены в панелях сервисов: убрать их из кода мало.
- Выката не было: ждём часы работы и переменные окружения. Агент не
  спрашивает «выкатывать?», пункты лежат в очереди.
