# Запись в DEPLOY-QUEUE.md

Одна строка-пункт на пачку. Очередь живёт в корне проекта, сверху
строка «Выкатываем только по слову владельца». После выката пункт не
удаляется, а помечается датой выката.

Формат:

```
- <ДД.ММ.ГГГГ> · <коммит или ветка> · <что сделано, по-человечески>. Зачем: <какой запрос или проблема>. Смотреть после выката: <какие страницы, запросы, позиции, клики, консоль, счётчик>. Не выкачено.
```

Пример (вымышленный):

```
- 01.10.2026 · abc1234 · гайд по генератору видео X: новый раздел «как оживить фото без водяного знака» и три вопроса в FAQ под запросы Вебмастера. Зачем: кластер показывается на позициях 7-10 без кликов. Смотреть после выката: позиции кластера через неделю, появились ли клики, собрался ли сниппет FAQ. Не выкачено.
```

После выката заменить «Не выкачено» на «Выкачено ДД.ММ.ГГГГ», дописать
«Индексация: Search Console, IndexNow» с датой и через неделю дописать,
что показал замер (`aivfx-track`).
