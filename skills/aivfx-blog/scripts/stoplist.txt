# Стоп-лист примет нейросети для check_text.py
#
# Формат:
#   фраза                     - ищется без учёта регистра, как подстрока по границам слов
#   re:регулярка              - регулярка Python, без учёта регистра
#   ... => совет              - совет печатается рядом с находкой
#   ## Раздел                 - название раздела для всех строк ниже
#   # комментарий             - пропускается
#
# Слова с окончаниями задавай регуляркой, иначе «является» поймается,
# а «являются» нет. Находка не приговор: «уникальный идентификатор»
# законен, решает человек.

## Канцелярит
re:\bявля(ется|ются|лся|лась|лось|лись|ясь)\b => глагол или тире-связку замени простым «это» или перестрой фразу
re:\bосуществля(ет|ют|ть|ется|ются|л|ла|ли)\b => «делает», «доставляет», «платит» - назови действие
re:\bосуществлени[еяю]\b => назови действие глаголом
re:\bданн(ый|ая|ое|ого|ой|ому|ую)\b(?!\s+(для|о|об|по|из|в)\b) => «этот» или название
re:\bв рамках\b => «в», «на», «при» или убери
re:\bв целях\b => «чтобы»
re:\bпроизвод(ится|ятся|илось|илась)\b => активный глагол: кто что делает
на сегодняшний день => «сейчас» или дата
re:\bимеет место\b => «есть», «бывает»
re:\bвышеуказанн\w* => назови, что именно
re:\bв случае если\b => «если»

## Штампы
в современном мире => удали, начни с дела
re:\bв (наше|нынешнее) время\b => удали или дай дату
re:\bв эпоху\b => удали
re:\bважно (отметить|подчеркнуть|понимать|помнить)\b => удали, скажи сам факт
re:\bстоит (отметить|подчеркнуть|упомянуть)\b => удали
re:\bдавайте (разберёмся|разберемся|рассмотрим|погрузимся|посмотрим)\b => удали, начни с ответа
re:\bпогруз(имся|итесь|иться)\b => удали
re:\bне просто\b[^.!?\n]{1,60}?,\s*а\b => скажи, что это, без противопоставления
re:\bигра(ет|ют) (ключевую|важную|решающую|огромную) роль\b => скажи, что именно делает
ни для кого не секрет => удали
re:\bоткро(йте|ете) для себя\b => удали
re:\bключев(ой|ая|ое|ые|ую) (аспект|момент|фактор)\w* => назови сам аспект
re:\bинновационн\w+ => факт вместо оценки
re:\bуникальн(ый|ая|ое|ые|ую|ого|ой|ым|ых) (возможност|опыт|решени|предложени)\w* => что конкретно отличает
re:\bширок(ий|ого|ому) спектр\w* => перечисли или удали
re:\bпо сути\b => удали
re:\bкак (уже )?было сказано( выше)?\b => повтори подлежащее, абзац должен стоять сам
re:\bнеотъемлем\w+ част\w+ => удали

## Пустые вводные и выводы
re:\bв этой статье (мы )?(рассмотрим|расскажем|разберём|разберем|поговорим)\b => начни с ответа
re:\bтаким образом\b => проверь, не повторяет ли вывод вступление
re:\bв заключение(\s+(стоит|хочется|можно) сказать)?\b => дай следующий шаг или удали вывод
re:\bподводя итог\w* => дай следующий шаг или удали
re:\bнадеемся, (что )?(эта|данная) статья\b => удали

## Тройки прилагательных
# Порядковые и местоимения («второй, третий», «который») исключены, остальное решает человек.
re:\b(?!(?:перв|втор|трет|четв|пят|шест|котор|так|друг|люб|кажд|сво|наш|ваш|мо|тво|сам|весь|все|сво)[а-яё]*\b)[а-яё]{3,}(ый|ий|ой|ая|яя|ое|ее|ые|ие)\s*,\s*(?!(?:перв|втор|трет|четв|пят|шест|котор|так|друг|люб|кажд|сво|наш|ваш|мо|тво|сам|весь|все|сво)[а-яё]*\b)[а-яё]{3,}(ый|ий|ой|ая|яя|ое|ее|ые|ие)\s*(,|\bи\b)\s*(?!(?:перв|втор|трет|четв|пят|шест|котор|так|друг|люб|кажд|сво|наш|ваш|мо|тво|сам|весь|все|сво)[а-яё]*\b)[а-яё]{3,}(ый|ий|ой|ая|яя|ое|ее|ые|ие)\b => оставь одно слово, которое можешь доказать фактом

## Обещания дохода
re:\bзаработа(ете|ешь|ете до|ть до)\b => что человек получит на деле, без суммы дохода
re:\bпассивн(ый|ого|ым) доход\w* => убери обещание дохода
re:\bгарантированн(ый|ая|ое|ые|ого|ую) (доход|результат|заработ)\w* => убери гарантию
re:\bокупится за\b => убери, если нет посчитанного примера с пометкой «пример»
re:\b(x|х)\s?[2-9]\d?\s+к\s+(продажам|доходу|прибыли)\b => убери множитель без источника

## Выдуманный опыт
re:\b(мы\s+)?(провер|протестирова|отобра|изучи)(или|ли)\s+(сотни|десятки|тысячи)\b => пиши только то, что было: «проверил сам на двух тарифах»
re:\bза (годы|долгие годы|многие годы)( работы| практики)?\b => если стажа нет или он неизвестен, убери
re:\bнаши клиенты (обычно|часто|всегда)\b => только реальный случай или убери
re:\bпо нашему (опыту|многолетнему опыту)\b => если опыта нет, «на официальной странице», «в отзывах»
re:\bкак показывает практика\b => чья практика? дай источник или убери

## Пафос
re:\bреволюци(я|ю|онн\w+)\b => факт вместо пафоса
re:\bмени(т|ют) правила игры\b => скажи, что поменялось
re:\bнов(ая|ую) эр(а|у)\b => убери
re:\bмаги(я|ю|и)\b => убери
re:\bмечт(а|у) станов\w+ реальност\w+ => убери
